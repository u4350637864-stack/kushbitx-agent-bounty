# Mermail Tender Desk

## Name
Mermail Tender Desk

## Description
This skill processes tender/RFP/procurement emails and produces evidence‑linked bid/no‑bid decision packets.  
It leverages the Mermail MCP inbox/draft capabilities to search for procurement opportunities, inspect and clean messages, extract deadlines, values, eligibility gates, mandatory documents and submission channels, surface missing or conflicting requirements, produce a decision packet, and optionally create an unsent clarification draft.

## Tools
- mermail-search
- mermail-inspect
- mermail-extract
- mermail-surface
- mermail-decide
- mermail-draft
